a

应该可以推一下找到O(1)个位置可能成为最大的位置然后比一下就好了。当然我懒得思考直接暴力把n * n个位置的答案全部算出来然后比比较了。

b

原题说给一个l， r区间加一，但是可以reorder，于是问题转化成给最长的子序列加1，求最长的子序列长度。首先要算出有多少位置有数记为cnt，毕竟只有这些位置需要被加。因为必须做n手，我们贪心地考虑，第一手我们选择一个最长的子序列，后面n - 1手我们都只给一个数加1。那么我们最多一次给del = sum - （n - 1) 长的子序列加1，答案就是min(del, cnt)。需要开ll就一定要开ll！cf太险恶！

c

给两个n长的数组q和r，给个k，把r中的数作为余数，q中的数作为商，除数任选；凑出的数不超过k就消去这次的q[i], r[i], 求最多的操作数。显然q，r的顺序本身不影响答案，不妨先将两者分别排序。考虑对于一个余数，除数必然要大于它，现在r数组递增，则要求的除数也递增，那就需要商越小越好。遍历r，为了操作最多次，我们每次贪心地取满足要求的最大的商，把更小的数留到后面用，这样更优，对于r，最小的除数是r + 1,那存在p合法，当 r + p * (r + 1) <= k 推出 k <= (k - r) / (r + 1)， 只需找符合条件的最大的k就好了，只需要在排序后的q数组上二分即可。并且观察到f = (k - r ) / ( r + 1 ) 单调减，即每次找到的q[i]一定单调向左。

d

观察到已经有的v和x值是永远不变的，只有i的值会变，？不确定，于是我们只用考虑？和存在的i；可以注意到如果可以全部填I，一定是最优的，这是答案的一个下界，一种做法是在这个下界的基础上调整，即先考虑全部填I，再把一些位置换成V，又因为V和X的性质完全一样只有值不一样，可以全部当成V考虑再补上本该是X的贡献。（代码还没写，太狗屎了）。

e

观察到对于一个区间，如果有奇数个块（多于1）去掉中间块仍有奇数个，如果有偶数个块，去掉两边的块就有奇数个块，于是要使一个区间beautiful，当且仅当这个区间不只有一个块。问题转化为：给m个区间，要求每个区间内的数不完全相同，求能构造多少个n长的数组符合要求。显然，每个数字都有01两种选择，全部独立枚举不可能，考虑dp。令fi为01 再i处跳变且i左边的限制全部满足的方案数，考虑fi可以从fj处转移过来，那可以发现，数组在j处，i处（j < i）跳变，即闭区间[j + 1, i - 1]01情况相同，于是如果存在一个限制在上述区间内，就不满足只在j，i两点跳变，故可以从j转移到i的充要条件是j和i之间没有完整的限制区间。考虑右端点在i左边的左端点最靠右的线段p的左端点是r，r左边的点到i的区间都完整包涵p，故不能从r的左边所有点转移过来，而对于r右边的小于i的点都合法，故可以转移过来。于是fi = sum{fr+1, fi - 1}; 因而我们对于每个点需要维护r；又因为转移是算一个连续段的和，可以算一个f数组的前缀和优化转移，最后f[n + 1]就是答案。

a

算有几个位置跟最后一个位置不同就好了。

b

找状态栏最多可以装几个正常长度的，如果超过了，把鼠标放到最右边，一直点到全是正常长度的，然后移到最左边，关完就好了，可以发现上界是动两次鼠标。然后判一判特殊情况就好了。

c

第一眼看有点像合并果子那一题，你会想到一个贪心，每次找一个比相邻位置大的最小的位置，把它们合并。
然后发现这种做法只能O(n ^ 2)写，不行。观察发现，花两个数的大值把它们合成大的数，可以看作花大值的话费删掉小的数。于是正难则反，考虑每个数被谁删掉，每个数只会被左右两边第一个大于它的数里小的那个删掉，维护这个求和就是答案。上述做法也有问题，当出现两个相邻相等的数之后，上述算法中它们互为消去对方的最小值贡献为两倍它们的值，但实际贡献是一倍它们的值加上左右最近大值中小的那个。这个bug很难补上。事实上，考虑共n个数，有n - 1个数被消去，我们每次消去最小的数，它被左右两边小的数删掉，代价是那个数，删掉之后，这两个数紧贴，用大数消去小数的代价是大的那个，于是其中大的那个值总会被用上：要么现在用，要么小的那个数的另一侧全部被小的那个数消去完，剩下一个更大的数，此时之前那个大值被用上。于是，初始相邻两的数的最大值一定都在最终的答案中，钦定全局最大值的一个留下，它的两侧连边有一个不用，于是答案就是上述和减去一个最大值。（其实我也没完全想通）

d

可以发现从原multiset生成一个S的过程是复杂的，但是解空间是相对简单的：即一些能被生成的S。考虑怎样的S能被生成（即判定条件）。考虑S包涵k种数，于是剩下的数要在这些集合中且不是众数，意味着（没出现在S中的每一种数）的数量分别应小于等于出现在S中的数的总数量，这样出现的数才能把没出现的数“藏”在每个子集中，考虑“最不利原理”：出现在S中数的总数量大于没种没出现的数的总数量只需大于出现次数最多数的数的总数量，这样的S就是合法的。考虑一个数字总数为i的multiset，引入一种新的数字p，如果合法，那么一定能引入cnt[p]种同的s; 于是我们可以考虑一个类似背包的dp，对于每类数p，遍历multiset大小i，f[i] += f[i - cnt[p] ] * cnt[p], 最后答案取i > maxcnt 的 f[i]就好了。

e

思考：a不超过2^30于是可以维护29个位。对于要求的c，只需将所有的b对其每一个1都有就好了。把所有的a_i或在一起，可以找到对每一位，找到现在是否有1能够凑出这一位，把所有的数异或在一起，可以找出哪些地方有1但全被抵消掉了，那c跟异或和做与，结果跟c不同的位就是我们需要补的。然后只需要考虑每一个需要补的位的的最小总花费。（假了，因为b_i可以小于a_i，不是要严格等于a_i的，故或和和异或和不能反应真实情况）。（没有考虑到一位上有多个1的本质：用一个1满足当前的要求，用剩下的1满足后面的要求，有多个一永远是好的，大不只用1个一，剩下的全是0就好了）（题目顺序无关，可以考虑把所有a_i排开一列，对每一位操作就好了，况且就算按顺序操作前面的决定了就不会变了，只用关心后面的，不要想乱了）。于是可以从最高位向低位按位贪心：如果当前位有的1比需要的多，用一个1满足当前，一个1满足后面，剩下的1全为零，直接结束；若果当前位的1等于需要的，向后看；若当前位的1个数小于需要的，需要给此处买出一个1，取后面部分最大的数来补差价， 然后把选到的这个数置为0（消除它对后面的影响）；就好了。并且，由于最多有29位，于是最多需要30左右个数，我们把a数组排序，取最大的30个数是最优的。

A

尝试怎样的a, b满足要求。发现将0 - n-1 四个数四个数分组，每组中，4k + 0和4k + 3配对，4k + 1和4k + 2配对，只需要看n - 1模4剩多少个数，判断谁匹配不上就好了。

B

想要将k剩下，考虑有没有足够的数能够死在k前面。小于k的数一定可以死在k前面，比k大但比最大数小的数一定可以死在k前面，算这两类熟的总和和要求剩下的个数做比较就好了，注意等于k的数不只一个，需要判一下。

C

想只剩下a_i。先考虑a_1和a_n, 它们一定符合要求，不妨考虑a_1，把a2到an的所有数合成一个数，可以发现如果a1小于右边的数，我就取前缀最小，否则我就取后缀最大。于是可以发现，如果数列只剩两个数，一定可以把整个数列变成其中一个数。现在考虑a_i,要只剩下a_i，由于没个数不一样，不可能先把它变成别的数，再变回来，可以发现，对包涵a_i的区间进行操作一定是最后的几步。先考虑不包含a_i的区间，即a_i左边的所有数和右边的所有数。再观察，对于一侧的所有数，操作多次和操作一次没有区别，左边的数最终会变成左边的前缀最小，右边的同理。于是只剩下3个数，即a_1到a_i-1的前缀最小a_i和a_i + 1到a_n的后缀最大，于是：如果a_i比左边小，或者比右边大，就可以把数列变成包涵a_i的两个数，那么就能做到，否则不能。

D

首先可以发现如果初始1（cnt1）的个数小于等于k，alice就赢了，那如果初始1多于k个，alice减少k个。对于每个回合可以发现，alice必能减少k个1，但bob不一定增加k个1，即alice可以保证场上有的1是不增的。则可以考虑，性质1：如果bob增加的1少于alice，alice就赚。性质二：同时，如果出现连续的k个空白，bob就必胜（性质二有时是错的），性质三：对于某些1，我可以改变它的位置，即在bob添加一些1后删除位置i上的1，保留位置j上的1，相当于把i位置上的1移动到j位置上了。考虑使用性质1，3: 如果有很多的1，我们可以通过调整，让他们的位置尽量靠近中间，因为位置越靠近中间，新增k个越容易覆盖它们，造成重叠，使得增加的1不如减少的1多。考虑构造一种情况，使得无论bob如何增加，都会造成重复，即 k > n / 2，因为对于任何的1，我们可以把它放到中间，那么不管从哪里起一段k长的1，都覆盖中间的1，这样每次可以减少若干次1，终alice胜。再考虑充分性，如果k <= n / 2, 若最后剩一个1，bob都考虑从另一侧起点起一段k长的1，无论alice怎样消去，最终仍会剩下一个一，本质是不会产生重叠。

E

求一个n个数的数列删掉k个数的mex有几种情况，考虑到mex的性质，刻画问题时考虑对数值开桶然后转化。考虑桶，桶中的数分布应该是（从0-n）a b c d 0…0… e f 0 0….（a,b, c, d等是常数）这样的。那么可以得出对于前面一段连续有数字的区间，删掉所有的几，mex就是几，而从第一次断掉开始（出现0）删掉后面的数不影响mex，进而得出答案只会在前面连续的数当中。那么对于每一个数p，如果k >= cnt[p], 且k - cnt[p] 不超过 num = 前面连续的数每个数保留一个的剩下的个数加上后面不相干数的和，则p可以成为mex。感觉可以把num处理出来然后拿每一个k去二分？（不行，因为对k有左右两端点的限制）。那再考虑，对于每个数p，要使p成为mex，k需要在一个上下界之间，于是我们可以把每个p要求的k的上下界处理出来，放到数轴上上，那对于每个数k，被多少个线段覆盖，就能使多少个p成为mex。用线段树维护，或者差分维护。

发表于 2025-12-07 分类于 加训

a

先看尾字母，尾字母大的一定大。尾字母相同，x的多少控制尾字母的增减，比较即可。

b

若n是偶数，考虑直接反转。若n是奇数，直接反转回导致正中间的数是fixed point，考虑解决这个问题。于是只需要反转之后，再把中间到最右边反转就好了。

c

把数列划分成若干块，要求每块的和相等。找出一种划分，使得最长的块长t最短。可以发现，块数k再上下界1，n之间。总和是给定的，块数必须整除总和，这个块数才可能有答案。n小，可以从小到大枚举块数，判是否存在可行的构造。

d

可以得出，贪心地操作得到的就是最小的次数。一次操作只能改变左右两颗子树整体的节点的相对顺序，不能交换两颗子树内的点。于是判据就是：对于两颗子树，它必须包涵一个二的倍数长度区间的所有数（实际写的时候是在判所有有有两个叶子结点的子树，是不是其两个叶子结点是相邻的；其他等价判法都行），如果顺序不对，就交换一次。注意到这是满二叉树，可以用堆或者说线段树的方式存储。

e

把一个数组a分成n块，在每块的前或后加上块长度，组成新数组b。现给出b数组，判断是否有一合法的a数组可以构成之。由题意，可以发现有两类数， 一类是代表块长的，另一类是块内元素。是否合法取决于所有的块长数字是否自洽。由于直接给出b数组，那么既需要枚举哪些数是块长、哪些数是元素；还要判断这种组合是否合法。于是考虑用dp枚举所有情况。f[i]表示以a[1]到a[i]的部分是否合法。（这个dp试图把每个数当成块长）于是考虑转移，分两种情况，1.如果a[i]作为一个块的开始，那如果f[i - 1] = 1即i前面的都合法，则f[i + a[i]]也合法。2. 如果a[i]作为一个段的结尾，那只要f[i - a[i] - 1] = 1, f[i] 就是1。

f

给n条线段，每条有一个颜色。要求对于每条线段，求其离最近的异色线段的距离。考虑线段i，j，其距离要么是l_j - i_r, 要么是l_i - r_j即考虑i在j左边活着i在j右边的情况。虽然对于一条线段有左右两边，但我们不用一次处理两侧，我们可以做两次，一次考虑所有线段的左侧，另一次考虑所有线段的右侧（也能说是考虑对称性）。那我们第一次考虑所有线段左边最近的异色线段，第二次考虑右边。对于一次，我们要从左到右考虑所有的答案，并且知道对于一条线段，它被两个端点唯一确定，于是我们考虑扫描线：把每条线段拆成左右两个端点，维护当前右边的两个异色右端点（因为答案要求算最近的异色线段，若只维护最右的一个端点，要是与当前同色就炸了，其他若有多种冲突关系，可以再思考维护的点的种数）。遇到做左端点就更新最右的另个异色端点值，遇到右端点就算其答案，这样对于每条线段，我们就得到了所有左端点在其右端点左侧的线段与其最近的距离。右侧同理，一个取巧的办法是把左右的端点翻转，此时右端点就成了左端点，用左端点的逻辑再做一遍就好了。

有一个n个点，m条边的无向图，最初所有人都在1号点。有f个朋友，其中i号朋友的家在h[i], 有k个朋友没有车。每个有车的朋友可以捎带任意多个无车朋友回家当且仅当这这些无车朋友的家在此有车朋友从1号点回家的最短路上。现求最少的不能被捎带的无车朋友。其中k <= 6; 注意到k <= 6, 考虑状态压缩，即我一定可以用01串表示这6个人的组合情况，因此可以很方便地枚举出对于每个有车的朋友，哪些无车朋友的组合是他可以捎带的：把无车朋友家离1号点距离从小到大排序，对于每个组合，我们可以算从1号点顺序经过此组合中所有点再到此朋友家的距离等不等于从1号点到此有车朋友家的最短距离，若等于就行，不等于这种组合就不行。然后我们事先准备一个dp数组，表示算所有的组合最终是否合法。处理完每个有车朋友可以捎带的组合数组good后，我们更新dp数组：对于每种情况j，for s: dp[j] |= dp[j ^ s] & good[s] 即：j合法，当 s可被捎带且j除去s的部分可被捎带。这个对于每个有车朋友更新dp数组，很像分层地更新背包问题的答案，所以要倒着更新。
