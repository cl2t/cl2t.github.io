准备配置一下命令行环境

准备重新使用命令行的工作流，“享受高效工作”。

在这里记录一下相关操作，以备忘。

zim

  • .zimrc只记录zim框架的配置信息，zsh的配置要去.zshrc
  • 去.zimrc里把keybind 改成了vim 模式

neovim

  • 包管理器使用lazy
  • vim的接口一般是vim.opt.xxxxx或者 vim.fn.xxxx这种的
  • 插件配置时要先加载再使用
  • 当vim.o.background = “light” 是，tokyonight只会提供一个浅色的主题，即day
  • 去.zshrc里把$EDITOR改成了nvim
  • e for end w for word
  • b 到上一个词首
  • u for undo , ctrl r : the undo for undos
  • undo all changes for a line: U
  • p: word / sentence: put sth after / below the cursor, P: 粘贴在前面·
  • G: 去文尾，gg：去文首， 行号 + G： 去某行， ctrl + g查当前行号
  • 向前搜索/，向后搜索？，n前进，N后退
  • % 匹配下一个匹配上的（[{
  • :s/old/new/g ,把old换成new，加g对整句不加只换下一个
    • s前面可以加紧贴的前缀：
      -行号，行号：前后范围
      -%：对全文
      -前加%，后缀为gc：对全文并询问是否更改
  • :!执行一个终端命令
  • :r + 文件名或外部命令，将其内容粘贴到光标后
  • R: 进入更改模式
  • yw: 复制一个单词，类推
  • (:句首，）下一句首，中文会有问题
  • nyy: 向下复制n行
  • n回车：向下n行
  • daw:删掉包涵光标的单词
  • 介词：i:in a:around t:to f:forward

  • /< 右移或左移的动词，可用>>, >w这种

  • 一个文件算一个buffer，一个tab(类似tmux的window）可以开多个window（类似pane），一个window显示一个pane,但是关掉tab不会关掉里面的buffer
  • ：buffer查询buffer， buffer n 切到某一个buffer
  • ：split 上下分屏，vsplit左右分屏
  • 用了一个多光标插件，https://github.com/mg979/vim-visual-multi
  • 对于纯vimscript的插件，不能写opts table

tmux

  • 终端里tmux : 建一个新的session
  • 上下分屏：ctrl b “
  • 左右分屏：ctrl b %
  • 切换: ctrl + 方向键
  • 回去：tmux a
  • 选回去哪一个session：tmux attach -t 数字
  • 列出有的session：tmux ls
  • 挂起tmux：ctrl b d
  • 关闭一个session：ctrl d
  • 全屏： ctrl z 再按一下回来
  • ctrl d 关掉当前pane
  • 建新的window：ctrl b c
  • 选择别的window/session：ctrl b w/s
  • 切换下一种排列：ctrl b space

  • 左/右交换：ctrl b [/]

  • 在配置文件里开透传可以在tmux下用ranger能显示图片。

git

  • git init
  • git add: 加到暂存区
  • git commit -m “提交信息”: 本地提交
  • git remote add origin + 网址：第一次提交到某个仓库
  • git push origin master : 推到master分支，master可以改成别的分支
  • git status: 现在的状态
  • 删掉.git这个文件夹就跟git无关了。
  • git revert [commit id] 生成一个拿掉id次提交的版本
  • git reset [commit id] 强制回退到某一个版本，丢弃后面的提交，（如果这一个版本晚于远端的最新提交就无事发生, 早于就得选直接强制提交，丢弃远端更远的版本： git push -f 或者先pull下来，合并之后再push）
  • git clone: 从远端搞一个仓库（一个文件夹包涵所有内容）到当前文件夹下，不需要当前文件夹被init过。
