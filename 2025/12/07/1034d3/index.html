A

尝试怎样的a, b满足要求。发现将0 - n-1 四个数四个数分组，每组中，4k + 0和4k + 3配对，4k + 1和4k + 2配对，只需要看n - 1模4剩多少个数，判断谁匹配不上就好了。

B

想要将k剩下，考虑有没有足够的数能够死在k前面。小于k的数一定可以死在k前面，比k大但比最大数小的数一定可以死在k前面，算这两类熟的总和和要求剩下的个数做比较就好了，注意等于k的数不只一个，需要判一下。

C

想只剩下a_i。先考虑a_1和a_n, 它们一定符合要求，不妨考虑a_1，把a2到an的所有数合成一个数，可以发现如果a1小于右边的数，我就取前缀最小，否则我就取后缀最大。于是可以发现，如果数列只剩两个数，一定可以把整个数列变成其中一个数。现在考虑a_i,要只剩下a_i，由于没个数不一样，不可能先把它变成别的数，再变回来，可以发现，对包涵a_i的区间进行操作一定是最后的几步。先考虑不包含a_i的区间，即a_i左边的所有数和右边的所有数。再观察，对于一侧的所有数，操作多次和操作一次没有区别，左边的数最终会变成左边的前缀最小，右边的同理。于是只剩下3个数，即a_1到a_i-1的前缀最小a_i和a_i + 1到a_n的后缀最大，于是：如果a_i比左边小，或者比右边大，就可以把数列变成包涵a_i的两个数，那么就能做到，否则不能。

D

首先可以发现如果初始1（cnt1）的个数小于等于k，alice就赢了，那如果初始1多于k个，alice减少k个。对于每个回合可以发现，alice必能减少k个1，但bob不一定增加k个1，即alice可以保证场上有的1是不增的。则可以考虑，性质1：如果bob增加的1少于alice，alice就赚。性质二：同时，如果出现连续的k个空白，bob就必胜（性质二有时是错的），性质三：对于某些1，我可以改变它的位置，即在bob添加一些1后删除位置i上的1，保留位置j上的1，相当于把i位置上的1移动到j位置上了。考虑使用性质1，3: 如果有很多的1，我们可以通过调整，让他们的位置尽量靠近中间，因为位置越靠近中间，新增k个越容易覆盖它们，造成重叠，使得增加的1不如减少的1多。考虑构造一种情况，使得无论bob如何增加，都会造成重复，即 k > n / 2，因为对于任何的1，我们可以把它放到中间，那么不管从哪里起一段k长的1，都覆盖中间的1，这样每次可以减少若干次1，终alice胜。再考虑充分性，如果k <= n / 2, 若最后剩一个1，bob都考虑从另一侧起点起一段k长的1，无论alice怎样消去，最终仍会剩下一个一，本质是不会产生重叠。

E

求一个n个数的数列删掉k个数的mex有几种情况，考虑到mex的性质，刻画问题时考虑对数值开桶然后转化。考虑桶，桶中的数分布应该是（从0-n）a b c d 0…0… e f 0 0….（a,b, c, d等是常数）这样的。那么可以得出对于前面一段连续有数字的区间，删掉所有的几，mex就是几，而从第一次断掉开始（出现0）删掉后面的数不影响mex，进而得出答案只会在前面连续的数当中。那么对于每一个数p，如果k >= cnt[p], 且k - cnt[p] 不超过 num = 前面连续的数每个数保留一个的剩下的个数加上后面不相干数的和，则p可以成为mex。感觉可以把num处理出来然后拿每一个k去二分？（不行，因为对k有左右两端点的限制）。那再考虑，对于每个数p，要使p成为mex，k需要在一个上下界之间，于是我们可以把每个p要求的k的上下界处理出来，放到数轴上上，那对于每个数k，被多少个线段覆盖，就能使多少个p成为mex。用线段树维护，或者差分维护。

F

除1外，要求位置i上的数p_i和i有gcd，我们可以考虑把一个数的所有倍数轮换一下，如2, 4, 6, 8 变成 8， 2， 4， 6，但是可能重复，比如2的倍数和4的倍数会重一部分，于是我们只考虑质数的倍数，并且把用过的判掉就好了。
