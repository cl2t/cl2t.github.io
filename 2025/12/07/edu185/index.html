a

应该可以推一下找到O(1)个位置可能成为最大的位置然后比一下就好了。当然我懒得思考直接暴力把n * n个位置的答案全部算出来然后比比较了。

b

原题说给一个l， r区间加一，但是可以reorder，于是问题转化成给最长的子序列加1，求最长的子序列长度。首先要算出有多少位置有数记为cnt，毕竟只有这些位置需要被加。因为必须做n手，我们贪心地考虑，第一手我们选择一个最长的子序列，后面n - 1手我们都只给一个数加1。那么我们最多一次给del = sum - （n - 1) 长的子序列加1，答案就是min(del, cnt)。需要开ll就一定要开ll！cf太险恶！

c

给两个n长的数组q和r，给个k，把r中的数作为余数，q中的数作为商，除数任选；凑出的数不超过k就消去这次的q[i], r[i], 求最多的操作数。显然q，r的顺序本身不影响答案，不妨先将两者分别排序。考虑对于一个余数，除数必然要大于它，现在r数组递增，则要求的除数也递增，那就需要商越小越好。遍历r，为了操作最多次，我们每次贪心地取满足要求的最大的商，把更小的数留到后面用，这样更优，对于r，最小的除数是r + 1,那存在p合法，当 r + p * (r + 1) <= k 推出 k <= (k - r) / (r + 1)， 只需找符合条件的最大的k就好了，只需要在排序后的q数组上二分即可。并且观察到f = (k - r ) / ( r + 1 ) 单调减，即每次找到的q[i]一定单调向左。

观察到已经有的v和x值是永远不变的，只有i的值会变，？不确定，于是我们只用考虑？和存在的i；可以注意到如果可以全部填I，一定是最优的，这是答案的一个下界，一种做法是在这个下界的基础上调整，即先考虑全部填I，再把一些位置换成V，又因为V和X的性质完全一样只有值不一样，可以全部当成V考虑再补上本该是X的贡献。（代码还没写，太狗屎了）。

e

观察到对于一个区间，如果有奇数个块（多于1）去掉中间块仍有奇数个，如果有偶数个块，去掉两边的块就有奇数个块，于是要使一个区间beautiful，当且仅当这个区间不只有一个块。问题转化为：给m个区间，要求每个区间内的数不完全相同，求能构造多少个n长的数组符合要求。显然，每个数字都有01两种选择，全部独立枚举不可能，考虑dp。令fi为01 再i处跳变且i左边的限制全部满足的方案数，考虑fi可以从fj处转移过来，那可以发现，数组在j处，i处（j < i）跳变，即闭区间[j + 1, i - 1]01情况相同，于是如果存在一个限制在上述区间内，就不满足只在j，i两点跳变，故可以从j转移到i的充要条件是j和i之间没有完整的限制区间。考虑右端点在i左边的左端点最靠右的线段p的左端点是r，r左边的点到i的区间都完整包涵p，故不能从r的左边所有点转移过来，而对于r右边的小于i的点都合法，故可以转移过来。于是fi = sum{fr+1, fi - 1}; 因而我们对于每个点需要维护r；又因为转移是算一个连续段的和，可以算一个f数组的前缀和优化转移，最后f[n + 1]就是答案。
